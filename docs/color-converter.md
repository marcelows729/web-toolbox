# カラーコード変換

URL: /tools/color-converter。既存37ツールに同等機能はなく、一般カテゴリに1件追加して38件。registryから検索・お気に入り・最近使用へ統合し、READMEとsitemapを既存スクリプトで同期する。

## 入出力と丸め

- HEX: #RGB / #RRGGBBのみ。大小文字を受理し、出力は大文字6桁。透明度なし。
- RGB: 各0〜255の整数。小数・符号・指数・%・関数表記は不可。
- HSL: Hは−360000〜360000度、S/Lは0〜100%、小数6桁まで。Hは360度で循環（−120=240、360=0）。各数値を別欄へ入力し、単位記号は不要。
- 全角ASCII英数字・記号を半角として解釈し、前後空白を除去。空欄は0にせず拒否し、範囲外・非有限・不正値も拒否。各入力32 UTF-16単位まで。入力を切り捨てて変換しない。
- 不透明な8bit sRGB。HSLからRGBは各成分を四捨五入（0.5切り上げ）し、そのRGBから全形式と色見本を生成。HSL表示は小数4桁まで、末尾0を省略。黒白グレーのH/Sは0。丸め後の色が入力HSLと異なる場合がある。
- 計算式の参考: [W3C CSS Color 4: HSLとsRGBの変換](https://www.w3.org/TR/css-color-4/#hsl-to-rgb)。本ツールは範囲を制限し、無彩色の色相を0で表示する。

## 状態・プライバシー

明示的に「変換する」を実行。入力/形式変更・再変換・リセットで結果/エラー/コピー通知を無効化。各形式を独立コピーし、共通useClipboardFeedbackのrevisionで遅延成功/失敗と競合コピー・離脱後の通知を抑止。すでに開始されたOSへの書き込み自体は取り消せない。失敗時は読取専用出力欄から手動コピーを案内する。

Reactの画面内状態だけで保持し、入力/結果を保存・送信・URL埋め込みしない。棚は既存ツールIDだけ。依存/API/設定追加なし。透明度/CMYK/広色域/AI配色/スポイト権限は対象外。

## 検証

通常npm testへ計算/入力/登録テストを追加。黒白・原色補色・全256グレー・4096色の表示HSL往復、色相循環・0.5丸め前後、全角/空欄/不正/範囲外を検証。既存専用headless CDP方式のtests/color-converter-browser.mjsを全体回帰へ組み込み、320/375/768/1280px・Light/Dark、キーボード/hover/focus/コピー、入力変更/遅延成功失敗/再変換/リセット/離脱/競合を確認。実機Safariと実スクリーンリーダーは検証対象外。
