# お気に入り・最近使用の信頼性点検（2026-10-02）

34ツールの既存仕様を点検した。お気に入りは追加順の逆順、最近使用は重複を除く最大8件、保存は端末内のIDのみ。複数タブの同時保存は従来どおり最後の保存全体を優先する。入力・結果・診断回答の保存、保存形式の変更、配信設定の変更はない。

## 再現した不具合と修正

- タブAの保存通知をタブBで遅延させ、その間にBで新しい保存を行うと、通知の古い `newValue` がBの表示を上書きした。実際の保存先と表示が食い違うため、通知受信時には保存先の現在値を読み直す。遅延した削除・clearの通知も同様に扱う。
- Bの書き込みを拒否した状態でAが保存すると、Bの保存不可案内が消えた。外部タブからの読み取りでは書き込みの成功を確認できないため、案内はB自身の保存が成功するまで維持する。同期時の読み取りが失敗した場合は画面内の状態を維持し、案内を表示する。

`tests/tool-shelf-browser.mjs` は専用headless Edgeの2タブで実際に発生したStorageEventのコールバックを遅延させる。架空のイベントを生成しない。保存不可は当該タブだけのStorageメソッド／getterへの例外注入で検証する。
