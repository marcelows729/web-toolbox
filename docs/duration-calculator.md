# 時間の足し算・引き算

URL: /tools/duration-calculator。日付や時刻に依存しない動画・作業などの時間量を加減算する。

## 仕様

- 最大20行。時間0〜999,999、分・秒0〜59の整数。空欄は0、全角数字を受理する。
- 符号は各行の「足す」「引く」で指定。入力の小数、符号、単位、桁区切り、不正文字は拒否する。
- 全行を整数秒で合算し、24時間で巻き戻さない。絶対値上限71,999,999,980秒。負号は結果全体に適用し、0は符号なし。
- 時間・分・秒の合計、HH:MM:SS、合計分（小数6桁まで四捨五入）、正確な合計秒を表示し、全部まとめてコピーする。
- 入力／操作変更・追加・削除・リセット時に結果、エラー、コピー通知を消す。コピー完了が遅れても古い通知を再表示しない。
- 行追加で新しい時間欄にフォーカス、削除で近くの行、リセットで最初の時間欄へ移動する。
- 入力は画面のReactメモリだけ。保存・送信・URL埋め込みなし。既存のfavorite/recentはツールIDだけを記録する。
- 日付・時刻・タイムゾーン・給与や法定労働時間は対象外。新依存・配信設定の変更なし。

## 検証手順

Node24で npm test / npm run lint / npm run build / git diff --check。
専用EdgeのCDPを9222、previewを5173で起動して node tests/duration-browser.mjs。
本番は TEST_BASE_URL=https://poketsuru.com を設定して同じ試験を実行する。
画像の保存先は TEST_SCREENSHOT_DIR（既定はTEMP）。light/dark、1280px/320pxの入力と結果を保存する。

時間量テストは59秒+1秒、23時間+2時間、27時間、負数、0、全角、空欄、不正文字、20行と上限、2000通りの表示保存則を確認する。
ブラウザ試験は20行の最大正負合計、結果・通知の消去、実Clipboard、Tab/Enter、コピー完了競合、検索・棚・ページ移動時の入力消去、単位・Timestampの代表変換を確認する。
既存の tests/browser-regressions.mjs で全27件のURL判定・画像処理とlight/dark320pxを検証する。
実機Safariは利用できないため未検証。
