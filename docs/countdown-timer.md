# カウントダウンタイマー

既存33ツールには経過時間計測のみで、残り時間のカウントダウンはないため1件追加。

- 時間0〜24、分秒0〜59の半角整数、空欄0。合計1秒〜24時間。
- 計測中・一時停止中は入力を固定。変更はリセット後。終了後はリセットか時間変更で再開始。
- リセットは指定時間を維持して開始前へ戻す。離脱・再読込・ブラウザ終了では入力と状態を消去。
- 注入した単調時計の起点差分で計測。負・逆行・非有限値を防御、終了は1回の状態遷移。
- 250msで確認、秒の表示/状態が変わる場合のみReact更新。背景では確認タイマー停止、復帰時に差分を取得。
- 残り秒は切り上げ、残り0で終了。古い確認コールバックも現在のモデルを読むのでリセット後に旧計測を終了させない。
- 時計表示はaria-live off、状態の操作と終了だけpolite通知。
- 音/通知/振動/権限なし。スリープや終了・再読込をまたぐ継続、厳密な期限は保証しない。
- 入力/状態はメモリだけ。保存/通信/URLなし、既存棚はIDのみ。依存・配信設定変更なし。

## 検証

- npm test 142件、lint（警告なし）、build、diff check成功。1秒・0禁止・24h境界・pause/resume・終了境界・連打・reset後の旧更新・改入力・long gapを注入時計で検証。
- 全体headless回帰で170ルート、76明暗モバイル、診断80レイアウト、ストップウォッチ/幅変換/文字数/縦横比/置換/画像処理が成功。カウントダウン専用回帰で明暗1280/320、native Enter/Tab、入力固定、終了通知1回、秒切り上げ、終了後resetとfocus、改入力、離脱/再読込、reduced-motion、ID-only保存を確認。画像を目視。
- 開発Strict Modeのeffect再実行で初期モデルが消える現象を一覧からのSPA移動で再現し修正。開発モードの専用全ケース、最終のdev/公開用ビルドのSPA開始→1秒終了→reset/focusを確認。Strict Modeの再セットアップ時だけモデルを初期化し、実際の離脱では消去する。
- 背景のlong gapとvisibility処理は時計注入/シミュレーションで検証。headlessの実背景タブは未検証。ストップウォッチ回帰もTEST_NATIVE_BACKGROUND=0でその項目だけ明示SKIP。
- 表示付きEdge、新依存、OS時計/電源設定変更なし。本番の操作/目視、実背景切替は親側クラウドブラウザに引き継ぐ。実機Safari・OSスリープ精度は未検証。
