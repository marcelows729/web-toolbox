# Development Environment

## Local Environment

* OS: Windows
* Editor: Visual Studio Code
* Git client: Git / Git Bash
* Runtime: Node.js
* Package Manager: npm

## Frontend

* React
* TypeScript
* Vite

## Development Server

```bash
npm run dev
```

Default URL:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

Build output:

```text
dist/
```

## Repository

GitHubを利用する。

## Hosting

Cloudflare Pagesを予定する。

GitHubのmainブランチへの更新を契機として自動デプロイする構成を想定する。
