# 世界時計

- URL `/tools/world-clock`。既存39ツールに現在時刻の都市比較はなく、datetimeに追加して40件。Timestampは任意日時/Unix変換、既存タイマーは時間量の計測であり重複しない。
- 東京（Asia/Tokyo）・UTCを固定基準、ニューヨーク・ロンドンを加えた4つを初期表示。追加候補はロサンゼルス・パリ・シドニーを含む計7地域。最大6つ、同一ID重複なし。基準以外は外し、順序は初期/追加順。選択の保存、任意地域入力、任意日時変換、予定・通知・位置取得なし。
- Date.nowの端末時計を1回取り、全地域を同じ瞬間で表示する。Intl.DateTimeFormatのIANA zone、Gregorian、ラテン数字、h23、longOffsetで地域の日付・日本語曜日・HH:mm:ss・UTC±HH:mmを生成する。時差/DSTを手書き定数や端末の標準時差で求めない。0オフセットもUTC+00:00と表示する。
- 表示更新は約1秒。表示中のみintervalを持ち、非表示・pagehide・アンマウントで解除する。visibilitychange/pageshowでDate.nowを取り直す。遅れたtickを足し算で積み上げない。pagehide後にvisibilitychangeだけで再起動せず、pageshowで再開する。cleanupはintervalと各listenerを解除し、保留tickもactiveフラグで抑止する。
- 秒更新の一覧はaria-live=off。都市は見出し・国/地域、日付/時刻/UTC差はdl、time要素のdatetimeは対応するUTC瞬間。選択/追加/削除・コピー結果だけをpolite通知する。ラベルと通常button/selectでキーボード操作でき、色だけで基準を示さない。
- コピーはクリック時に1回取った端末時刻の全都市スナップショット。UTCのISO瞬間と各地域の年月日/曜日/秒/オフセットを同じ順序で記録し、画面をその瞬間へ更新する。コピー内容欄は固定し、通常の秒tickでは変更・通知取消をしない。都市候補の選択/追加削除/リセット・新しいcopy・pagehide・離脱で古い完了/失敗通知を抑止する。Clipboard拒否/非対応時は手動コピー欄を残す。
- 端末時計の誤差やブラウザのtimezoneデータの古さは補正しない。ネットワーク時刻同期を行わず、法律変更などの最新地域時刻情報やOSスリープ中の表示更新、精密な時刻一致を保証しない。Intl情報が利用できなければ明示的なエラーとし、固定時差へフォールバックしない。
- 時刻・選択・コピー内容はページメモリのみ。再読込/SPA離脱再入場で初期表示。BFCacheの復帰ではメモリ内の選択を維持し現在時刻を再取得する。URL/storage/外部へ渡さず、棚はツールIDのみ。新依存・外部API・設定変更なし。

## 検証と親QA

固定日時で7地域の夏冬、米国/欧州/豪州のDST開始終了、日付/年跨ぎ、真夜中00時、単一瞬間のコピー、上限・重複・基準維持を検証する。全test/lint/build/diffと既存専用headlessのlight/dark・320/375/768/1280・keyboard・実Clipboard・遅延/競合copy・visibility/pagehide/pageshow/SPA離脱のtimer/listener cleanupを確認する。

- 2026-07-15T12:34:56Z: 東京21:34:56 +09、NY08:34:56 −04、London13:34:56 +01、Sydney22:34:56 +10。
- NY 2026-03-08T06:59:59Z→07:00:00Z: 01:59:59 −05→03:00:00 −04。
- 2025-12-31T23:59:59Z: 東京は2026-01-01（木）08:59:59、UTCは2025-12-31（水）23:59:59。
- 初期4→LA/Paris追加で6、Sydney追加は上限で無効。NYを外すとSydneyを追加可。候補に表示中都市は出ない。
- 実際の画面は常に端末の現在時刻。コピーのUTC基準ISOを同じ瞬間の比較に使う。時計欄を連続読み上げしない。コピー内容は操作時点として固定する。
