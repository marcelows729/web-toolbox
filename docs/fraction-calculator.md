# 分数計算

- URL: `/tools/fraction-calculator`。既存38ツールには2つの分数の四則演算がなく、generalへ追加して39件。
- 分数1・分数2の整数分子/分母を明示入力し、足す・引く・掛ける・割るを選んで計算する。初期値とリセットは1/2 + 1/3。自動計算や履歴は追加しない。
- 各整数は符号を除いて18桁以内。先頭0も桁数に含む。前後空白・符号込みで1欄32 UTF-16単位まで。全角数字/＋/－とU+2212の負号を受理。内部空白、空欄、小数、カンマ、指数、式・帯分数入力は拒否。
- 32文字を超えた編集・貼り付けは切り捨てず拒否し、直前入力を保持して結果・コピー通知を消す。入力を修正するまで計算を無効にする。
- 分母0を拒否し、割り算では第2分数の分子0も拒否。負の分母は分子へ符号を移す。BigIntの整数演算とユークリッドの最大公約数で入力・結果を約分する。結果は分母正、0は0/1に正規化、分母1なら整数表示。上限から計算後の分子は最大37桁、分母は最大36桁で処理は有限。
- 仮分数にだけ正確な帯分数を併記する。正は `1 + 1/6`、負は全体を負にする `−(1 + 1/6)`。小数表示は提供せず、丸めや循環小数の誤表示を作らない。
- HTMLのfieldset/legendと分子・分母ラベル、select、submit、既存CalculationPageを使う。既存青・濃紺テーマとレスポンシブを維持。数式描画の依存は追加しない。
- 入力・操作変更、再計算、リセット、離脱で古い結果とコピー通知を抑止する。既存useToolResultで遅延Clipboard・失敗・競合を扱う。入力/結果/設定は画面メモリだけ。保存・送信・URL埋め込みはせず、棚はIDのみ。
- 新依存/API/サービス/配信設定なし。登録・検索・棚・lazyルート・README・sitemapを同期。

実iOS/Android・Safari、全入力とOSのClipboard挙動は未検証。

## 代表例

- 1/2 + 1/3 → 5/6
- 1/2 − 1/3 → 1/6
- 2/3 × 3/4 → 1/2
- 2/3 ÷ 4/5 → 5/6
- 7/6 + 0/1 → 7/6、帯分数1 + 1/6
- −7/6 + 0/1 → −7/6、帯分数−(1 + 1/6)
- 1/−2 + 1/3 → −1/6
- 0/3 + 0/5 → 0
