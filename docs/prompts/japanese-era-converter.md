# Japanese Era Converter Implementation

## 目的

「ぽけつる / POKETSURU」に、新しいツールとして「西暦・和暦変換」を追加する。

西暦の日付を和暦へ変換し、和暦の日付を西暦へ変換できる日本向け一般ツールとする。

既存の設計・Tool Registry・Routing・Theme・共通UIルールに従うこと。

特にUIについては、`docs/tool-development-guide.md`に記載されている共通UIルールを優先し、今回のために独自デザインを増やさない。

---

英語名: Japanese Era Converter

## 3. 基本機能

同一ページ内に以下の2方向の変換を用意する。

1. 西暦 → 和暦
2. 和暦 → 西暦

視覚的に分けて表示する。

---

## 4. 西暦 → 和暦

- input type="date" を使う。
- 例: 2019-05-01 → 令和元年5月1日
- 対応元号: 明治, 大正, 昭和, 平成, 令和
- 元号開始日を正確に扱う
  - 明治: 1868-01-25
  - 大正: 1912-07-30
  - 昭和: 1926-12-25
  - 平成: 1989-01-08
  - 令和: 2019-05-01
- 明治は簡潔に扱う
- 元号の境界は正しく判定する
  - 2019-04-30 → 平成31年4月30日
  - 2019-05-01 → 令和元年5月1日
  - 1989-01-07 → 昭和64年1月7日
  - 1989-01-08 → 平成元年1月8日
  - 1926-12-24 → 大正15年12月24日
  - 1926-12-25 → 昭和元年12月25日
- 元年は「元年」と表示
- 1868-01-24 以前は対応範囲外エラー

---

## 5. 和暦 → 西暦

以下を入力できる。

- 元号
- 年
- 月
- 日

元号は選択式。例:

- 元号: 令和
- 年: 5
- 月: 4
- 日: 1

→ 2023年4月1日

必要に応じて ISO 表記の補助表示を含める。

---

## 6. 元年

年=1 は元年として扱う。

UI上で明示的に「元年」を選択しなくても、処理として `1 -> 元年` と扱える。

---

## 7. 和暦 → 西暦の計算

- 元号ごとの開始西暦を基準に計算する。
- 元号の開始日・終了日を超えた日付は不正とする。
- ただし、単純な年加算だけで終わらせない。

---

## 8. Validation

### 元号範囲Validation

- 平成31年4月30日 → 有効
- 平成31年5月1日 → 無効
- 令和元年4月30日 → 無効
- 昭和64年1月7日 → 有効
- 昭和64年1月8日 → 無効

### 日付Validation

以下は不正とする。

- 年が空
- 年が0以下
- 年が整数でない
- 月が1〜12以外
- 存在しない日
- 2月30日
- 4月31日
- 元号範囲外の日付

JavaScript Date の自動補正で 2月30日 → 3月1日 とされないよう、明示的にチェックする。

## 9. UI

`docs/tool-development-guide.md` の共通UIルールに従う。

- Primary Action: ブランドブルー背景・白文字
- Selected State: ブランドブルー背景・白文字
- Secondary: Neutral
- Light / Dark でコントラストを維持
- 西暦 → 和暦 と 和暦 → 西暦 はパネルとして分ける
- パネル間の余白は既存の日付・日数計算ツールと同じ考え方にする
