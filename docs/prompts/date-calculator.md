# Date Calculator Implementation

## 目的

「ぽけつる / POKETSURU」に、新しいツールとして
「日付・日数計算」を追加する。

2つの日付の間の日数を計算したり、指定した日付から「○日後 / ○日前」の日付を計算できる、シンプルで使いやすいブラウザ完結型ツールとする。

開発者だけでなく一般ユーザーにも分かりやすいUI・日本語表現を重視する。

既存の設計・Tool Registry・Routing・UI・Themeの方針に従い、不要な共通化や大規模な変更は行わない。

# 4. 基本機能

同一ページ内に、以下の2種類の計算機能を用意する。

1. 日付間の日数計算
2. ○日後 / ○日前の日付計算

2つの機能が視覚的に分かるようにする。

---

# 5. 日付間の日数計算

開始日と終了日を入力して、その間の日数を計算する。

結果には以下の2つを表示する。

- 日付の差
- 開始日・終了日を含む場合

例:

開始日: 2026-08-01
終了日: 2026-08-02

結果:

- 日付の差: 1日
- 開始日・終了日を含む: 2日

---

# 6. 日数の基本定義

「日付の差」は開始日から終了日までに経過した日数。

同じ日付の場合は 0 日。

開始日・終了日を含む場合は、開始日と終了日の両方を 1 日として数える。

---

# 7. 開始日 > 終了日

開始日が終了日より後の場合でもエラーにはせず、
方向が分かる形で表示する。

例:

2026-08-22 → 2026-08-01

結果:

-21日

または

21日前

を表示してよい。

両端を含む日数は長さとして扱う。

---

# 8. ○日後 / ○日前の計算

基準日と日数を入力して、指定した日数だけ前後した日付を計算する。

例:

基準日: 2026-08-01
日数: 10
方向: ○日後

結果:

2026-08-11

---

# 9. 日数入力Validation

○日後 / ○日前の入力日数は、
0以上の整数のみ許可する。

以下はエラーとする。

- 空
- 負数
- 小数
- 数値以外

---

# 10. 日付Validation

以下を適切に扱う。

- 開始日未入力
- 終了日未入力
- 基準日未入力
- 不正な日付
- Dateとして扱えない値

ユーザーが原因を理解できる日本語エラーメッセージを表示する。

---

# 11. 日付計算とTimezone

「時刻」ではなく「カレンダー上の日付」を扱う。

入力された `YYYY-MM-DD` から UTC ベースで日付差を計算する。

`Date.UTC(year, month - 1, day)` を利用して差分を計算する。

---

# 12. ○日後 / ○日前とDST

日付加算についても UTC ベースで年月日を扱い、
ローカルTimezoneのDST影響を避ける。

結果は `YYYY-MM-DD` 形式で表示する。

---

# 13. うるう年 / 月またぎ / 年またぎ

- 2024-02-28 + 1日 → 2024-02-29
- 2024-02-29 + 1日 → 2024-03-01
- 2026-01-31 + 1日 → 2026-02-01
- 2026-12-31 + 1日 → 2027-01-01
- 2026-01-01 - 1日 → 2025-12-31

を正しく扱う。

日付・日数計算は、2つの日付の間の日数を調べたり、指定した日付から○日後・○日前の日付を計算したりできるツールです。

# 20. Usage

## 日付間の日数を調べる

1. 開始日を入力します。
2. 終了日を入力します。
3. 計算します。
4. 日付の差と、両端を含む日数を確認します。

## ○日後 / ○日前を調べる

1. 基準日を入力します。
2. 日数を入力します。
3. ○日後または○日前を選択します。
4. 計算結果の日付を確認します。
