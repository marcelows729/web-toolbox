# 画像の切り抜き

既存の画像サイズ変更・結合・回転は辺を切り取らないため、同等機能の重複なし。`image-crop` を一般カテゴリへ追加し、公開35ツールとする。旧ID・URLは維持。

## 操作と出力

JPG・PNG・静止WebPを1枚選び、左上を0とする位置・幅・高さで矩形を指定する。自由指定は1画素から。1:1・4:3・16:9は最大の中央矩形を選び、幅から高さを自動算出する。整数画素で比率を正確に保つため、それぞれ1・4・16 px単位の幅と最小1×1・4×3・16×9が必要。最小範囲より小さな画像で比率を選ぶと案内し、現在の範囲を保持する。範囲外は自動で切り詰めず、位置やサイズの修正を求める。

プレビューのドラッグは両方向に対応する。Tabでプレビューへ移動し、矢印で位置、Alt＋矢印でサイズ、Shift追加で10単位に変更できる。数値欄はネイティブ矢印でも操作できる。中央配置・画像全体への復帰・消去を用意する。プレビューの寸法を画面幅と高さ400px内に収め、極端な縦横比でも数値欄で操作できる。縮小表示のため、細部の最終確認は出力プレビューと保存画像で行う。

明示操作でPNGを生成する。元のEXIF反映後の画素に対し、整数の平行移動と出力Canvasの境界で切り抜く。拡大・縮小や再圧縮の繰返しをせず、常に元ファイルから生成する。透過を維持し、保存名に `-cropped.png` を付ける。背景を自動で消す機能ではない。

## 安全と共有範囲

既存 `useImageWork` の直列処理・revision・中断・画面離脱抑止と、`prepareImages` の内容形式・アニメーション・CRC・上限検査・EXIF反映・縮小プレビュー、`renderImages` の描画・PNG書出し・寸法検証・bitmap/Canvas解放を利用する。描画APIを増やさない。共通画面には切り抜き専用の短い説明分岐だけを追加する。

入力1枚8 MiB・各辺8192 px・1200万画素、出力各辺8192 px・1200万画素・16 MiBの既存制限を保持する。破損・形式偽装・SVG/GIF/HEIC・APNG/アニメWebPを拒否する。保存時のメタデータ完全除去や全端末のメモリ容量は保証しない。

ファイル選択・範囲変更・比率変更・消去は古い結果と処理revisionを無効にする。編集中は以前のダウンロードを残さない。最新ファイルの読込み完了で範囲を初期化し、遅延した古い処理は表示・保存に使わない。ファイル・名前・設定はこの画面のメモリだけに保持。外部送信・永続保存・URL埋込・新依存・配信設定変更なし。

## 検証

```powershell
npm test
npm run lint
npm run build
node scripts/sync-catalogue.mjs --check
git diff --check
node tests/image-crop-browser.mjs
node tests/rotation-browser.mjs
node tests/catalogue-browser.mjs
$env:TEST_NATIVE_BACKGROUND='0' # headlessでは実ウィンドウ切替を除く
npm run test:browser
```

専用headless EdgeのCDP9222とproduction preview5173を使い、同じページを順番に操作する。既存ストップウォッチの実ウィンドウ切替と実機Safariは検証対象外。背景化の実タブ検証は親側のブラウザで確認する。

純粋テストは14,400通りの小寸法・全位置矩形と、各固定比率で65×45の全寸法、無効値・端・キーボードの境界を照合する。ブラウザはRGBA配列による独立した矩形抽出とPNG出力を比較し、透過・WebP・全EXIF・極小/端/8192×1/1×8192、ネイティブキーとドラッグ、エンコード/デコードの遅延・差替え・消去、非対応・破損・巨大・アニメ画像、実ダウンロード、light/dark・320/1280px、入力非保存/非送信を検証する。一覧・検索・棚・サイトマップ・READMEも既存生成手順で同期する。

## 親スレッドでの本番確認

https://poketsuru.com/tools/image-crop を開き、透過PNGを自由矩形と1:1で切り抜いて保存する。JPEGを4:3・16:9にし、幅変更で高さが連動すること、画像外の数値を拒否すること、変更後に古いダウンロードが消えることを確認する。Tab・矢印・Alt/Shift＋矢印と数値欄だけで操作し、320pxのlight/darkも確認する。範囲を変更した後や別ファイル選択後に新しい処理が完了するまで古い結果を保存できないことを確認する。
