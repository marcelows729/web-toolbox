# 文字列の一括置換

- URL: `/tools/text-replace`、ID: `text-replace`、カテゴリ: テキスト・変換。既存の空白・空行・重複整形とは別の用途。
- 完全一致のリテラル置換。左から非重複で検索し、置換で作った文字列は再検索しない。検索空文字は禁止、置換空文字は削除。正規表現や `$&` の展開なし。
- 大小文字・半角全角・Unicode正規化を同一視しない。改行を含む3つの入力をtextareaで扱い、CRLF・CRをLFへ統一。元の本文は結果で上書きしない。
- UTF-16単位で本文50,000、検索1,000、置換10,000、結果100,000。切り捨てず拒否する。最初に非重複の一致数と結果長を数え、出力増幅の上限確認後に生成する。50,000文字の本文に対する有限の2回の検索で、無制限な再帰置換をしない。
- 入力・結果はメモリ内のみ。保存・送信・URL埋込みなし。既存の棚はIDだけ。編集・再実行・クリア・離脱は共通useToolResultのrevisionで古いコピー通知を無効化する。
- 遅延読込の明示ルートを追加。既存29ツールのID・URLを維持し公開30ツール。新依存・外部API・配信設定変更なし。

検証: `npm test` の文字列・Unicode・改行・削除・非重複・上限テスト、および `npm run test:browser` 内の `tests/text-replace-browser.mjs`。ブラウザでは実コピー、ネイティブEnter、明暗1280/320px、3入力の貼付上限、10万文字結果、エラーの説明関連、古いコピー完了、通信・保存・URLへの入力混入、既存整形を確認する。通常ブラウザ検証の両診断本文幅回帰も維持。
