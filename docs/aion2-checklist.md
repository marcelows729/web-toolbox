# AION2 日課・週課チェック

URL: `/tools/aion2-checklist`。AION2カテゴリの最初のツール。キャラクターと自由入力のタスクを管理する。必須日課・報酬・回数・リセット時刻の公式リストではなく、ゲームとの連携はしない。初期状態は空。日課/週課の未完了への変更は選択中のキャラクターだけに手動で適用する。

キャラ追加/名前編集/削除、タスク追加/本文と区分の編集/削除/完了チェック、区分別の進捗。直前の1変更だけ取り消せ、後続の変更・再読込・離脱で以前の取消履歴は失われる。タスク編集時には完了状態を維持する。

名前40・タスク120 UTF-16単位、改行なし、前後trim。20キャラ、1人100タスク、全体1000タスクまで。保存済み入力・完了状態だけを専用localStorageキー `poketsuru-aion2-checklist-v1` に保存する。編集途中の本文・取消履歴・復元プレビューはメモリのみ。URLと外部通信には載せず、既存棚の保存形式は変えない。

保存できない場合も画面内の変更は維持し、再読込で失われる旨とJSON退避/再試行を表示する。不正な保存JSONは自動で上書きしない。ブラウザのデータ消去・プライベートモード・共有PC・複数タブ同時編集には注意が必要。アカウント同期なし。

JSONは全キャラの本文と完了チェックを含むversion1形式。1 MiBまで、型/区分/boolean/ID一意性/文字数/件数を検査し、既知のフィールドのみ再構成する。復元候補の名前・件数・完了数と上書き範囲を表示し、確認チェックを入れて復元ボタンを押すまで現データと保存内容は変えない。候補の取消、復元操作の取消が可能。変更/新たな読込/離脱後の古い非同期完了は無視する。JSONに入力内容が含まれることを表示する。

検証は単体テスト、専用headless Edgeの明暗320/375/768/1280、キャラ切替・再読込・CRUD・手動リセット/取消・JSON書出し/検証/確認/復元・storage失敗・不正保存データ・入力エラー・キーボード・表示参照・送信なし。実機Safariとスクリーンリーダーの読み上げは未検証。

AION2データ保護レビュー: Web Locksで保存を行うタブを1つに限定し、保存前の生データ比較とstorage通知で古い全体データの上書きを止める。ロック非対応・競合時は画面内変更を保持しJSON退避を案内、競合データを勝手にマージしない。ロックは離脱で解放し、遅い獲得を無効化する。キャラ全体の削除とタスク削除は名前付き確認と対象IDを固定し、連打で次のキャラ/タスクへ波及させない。
