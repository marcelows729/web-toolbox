## 修正の範囲

useToolResultの変更はコピー試行番号と完了時の一致検査だけ。全16利用先を回帰確認する。既存BrowserTool本体、修正済み4ツールのコードは変更しない。

文字数・Text Diff・UUID・Timestampは、独自のライブ／複数結果を維持するため、テキストと成功メッセージを受け取るuseClipboardFeedbackを共有。リセット／再実行／離脱／後続コピーで古い通知を無効化し、Text DiffとTimestampの1.8秒の通知消去も維持する。

日付分割入力のonBlurは同じ値を通知するため、値が実際に変わった場合だけ結果を消す。計算関数・変換条件・乱数方式・QRの生成設定は変更しない。ツール登録・検索ID・装飾・依存関係・配信設定にも変更なし。入力を外部送信しない。

## 回帰手順

既存の専用Edge CDPとローカルpreviewを利用する。新しいブラウザ依存は不要。

```text
npm test
npm run lint
npm run build
git diff --check
node tests/remaining-results-browser.mjs
node tests/conversion-browser.mjs
node tests/text-formatter-browser.mjs
node tests/everyday-browser.mjs
npm run test:browser
```

remaining-results-browserは、全16共通利用先のコピー完了順逆転を両方向で確認し、各入力・設定変更、Clear、SPA画面離脱後のコピー成功／失敗を検査する。個別7ツールはライブ値・UUIDの同一性・差分コピー・独立した日付結果・入力エラー・現在日時操作・実QR PNGを確認する。遅延QRは実際のcanvas結果をPromiseで保留し、新しい結果と古い成功／失敗の順序を検査する。SHAはdigestを保留して編集後の古い完了を検査する。

残り22ツールのライト／ダーク320px、フォーカス・Tab、ネイティブEnter／入力、画面画像も確認。画像2ツールは既存test:browserで実デコード／出力競合を確認する。TEST_BASE_URLで本番、TEST_SCREENSHOT_DIRで画像出力先を指定できる。実機Safariは未検証。
