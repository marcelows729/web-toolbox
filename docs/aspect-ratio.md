# 縦横比・サイズ計算

URL `/tools/aspect-ratio`、ID `aspect-ratio`、カテゴリ「一般」。画像ファイルを使う既存リサイズとは別に、寸法だけで比率を約分・再計算する1ツール。プリセット1:1／4:3／3:2／16:9／9:16、元の寸法の縦横入替に対応。

元の幅・高さと新しい寸法は0より大きく1,000,000以下、小数6桁。全角数字対応。共有parseAmountの有限小数検査とBigInt分数を使用し、共通の整数スケールへ変換した比の最大公約数を計算する。小数の入力由来で正しい比が大きくなることはあるが、浮動小数由来の誤差は増やさない。計算する側も上限を超える場合は拒否する。

新しい寸法が空なら比率だけを計算。幅か高さの1つだけを固定し、もう一方を明示実行で計算する。入力同士を書き換えるeffectは使わない。入替・プリセットは元の幅高さだけに作用し、指定側と新しい寸法を維持する。

計算する側の整数四捨五入（0.5切上）／切上／切捨を選べる。丸め後0は拒否し、小数・切上等への修正を案内。表示寸法の比率を約分して併記し、差を明示する。小数モードは6桁の目安で「約」／「0.000001未満」を使い、正確な整数比と表示の近似を区別する。単位は利用者が揃え、dpiや印刷実寸への換算・保証はしない。

入力と設定はメモリだけ。既存useToolResultで編集・再実行・リセット・離脱後の古いコピー通知を無効化。明示的lazyルートを追加し、既存30ツールのID・URLを保持。新依存、通信、配信設定の追加なし。

検証は`npm test`の`tests/aspect-ratio.test.mjs`と、通常`npm run test:browser`に含めた`tests/aspect-ratio-browser.mjs`。実ブラウザでは明暗1280/320px、ネイティブTab/Enter、実コピー、全プリセットと指定方向、縦横入替、全角、小数、丸め差、各入力・計算側上限、エラー関連、入力相互更新がないこと、コピー競合・離脱、保存/通信/URLの確認、および単位変換の回帰を行う。
