# Requirements

## 目的

開発作業や日常業務で発生する細かな作業を効率化するWebツールを、一つのWebサイトから利用できるようにする。

小規模なツールを継続的に追加できることを重視し、ツール数が増えても目的のツールを探しやすいWebサイトを目指す。

---

## 対象ユーザー

初期段階では開発者本人を主な対象とする。

将来的には一般公開し、他の開発者や一般ユーザーも利用できるサービスとする。

---

# Version 0.1

Version 0.1では、Web Toolboxの共通基盤と最初のツールを実装する。

多数のツールを一度に実装するのではなく、新しいツールを継続的に追加できる仕組みを確立することを優先する。

---

## 1. 共通機能

### 1.1 ツール一覧

登録されているツールをトップページに一覧表示する。

各ツールには以下を表示する。

* ツール名
* 短い説明
* カテゴリ

ツールを選択すると個別ツールページへ遷移する。

---

### 1.2 ツール検索

ツールをキーワードで検索できる。

検索対象：

* ツール名
* description
* keywords

検索はブラウザ上で行う。

---

### 1.3 カテゴリフィルター

カテゴリを選択してツール一覧を絞り込める。

初期カテゴリ：

* 開発
* テキスト・変換
* 日時
* ネットワーク
* その他

カテゴリはツール数の増加に応じて追加・変更可能とする。

---

### 1.4 Tool Registry

各ツールの基本情報を一元管理する。

Tool Registryの情報を利用して、以下を生成することを想定する。

* トップページのツール一覧
* 検索
* カテゴリフィルター
* 関連ツール

詳細なデータ構造は `docs/tool-development-guide.md` で定義する。

---

### 1.5 個別URL

各ツールは固有のURLを持つ。

例：

```text id="7epuyk"
/tools/json-formatter
```

個別URLへ直接アクセスできること。

---

### 1.6 関連ツール

ツール詳細ページから関連する別のツールへ移動できる。

関連ツールが存在しない場合は表示しなくてもよい。

---

# 2. ツール詳細ページ

各ツールページは可能な限り以下の共通構成を使用する。

1. ツール名
2. 短い説明
3. ツール操作領域
4. ツールの説明
5. 使い方
6. 関連ツール
7. Privacy Information

ツールの性質によって不要なセクションは省略可能とする。

---

# 3. 初期実装ツール

Version 0.1では以下を実装する。

## JSON Formatter

JSON文字列を整形・圧縮する。

### Input

複数行のJSON文字列を入力できる。

### Format

JSONを解析し、読みやすい形式に整形する。

### Minify

JSONを解析し、不要な空白や改行を除去する。

### Clear

以下を初期化する。

* Input
* Output
* Error

### Copy

Outputをクリップボードへコピーする。

コピー成功時はユーザーに簡単なフィードバックを表示する。

### Error

JSONの解析に失敗した場合はエラーを表示する。

エラーによってアプリケーション全体が停止しないこと。

### Processing

JSONの解析・変換処理はすべてブラウザ上で実行する。

入力されたJSONをサーバーへ送信しない。

---

## SQL IN Generator

複数の値からSQLのIN句で利用できる値リストを生成する。

### Input

改行区切りまたはカンマ区切りの値一覧を入力できる。

### Processing

値の正規化、重複除去、SQL文字列エスケープ、数値バリデーションはすべてブラウザ上で実行する。

入力データをサーバーへ送信しない。

---

## Timestamp Converter

Unix Timestamp と日時を相互変換する。

### Input

Timestampまたは日時を入力し、秒/ミリ秒やLocal/UTCを選択して変換する。

### Processing

日時の変換処理はブラウザ内で完結し、入力データをサーバーへ送信しない。

---

## Character Counter

入力テキストの文字数・行数・単語数・UTF-8バイト数をリアルタイムに確認する。

### Input

複数行テキストを入力できる。

### Processing

文字数・空白除外・行数・単語数・UTF-8バイト数の計算はすべてブラウザ上で実行する。

入力データをサーバーへ送信しない。

---

## URL Encode / Decode

文字列やURLをURLエンコード・デコードする。

### Input

日本語・スペース・記号・絵文字を含む文字列またはURLを入力できる。

### Processing

Encode / Decode の処理はブラウザ上で実行し、入力データをサーバーへ送信しない。

---

## Base64 Encode / Decode

テキストをUTF-8として扱い、Base64へエンコード・デコードする。

### Input

日本語・英数字・記号・絵文字を含むテキストを入力できる。

### Processing

TextEncoder / TextDecoder と `btoa()` / `atob()` を用いてブラウザ内で変換し、入力データをサーバーへ送信しない。

---

# 4. 将来追加するツール候補

以下は候補であり、Version 0.1の実装対象ではない。

* UUID Generator
* Text Diff
* Base64 Converter

必要性や実際の利用頻度を見ながら順次追加する。

---

# 5. Privacy

ブラウザだけで処理可能なツールでは、ユーザーが入力したデータを外部サーバーへ送信しない。

そのようなツールでは、ツールページにブラウザ内処理であることを表示する。

将来的にBackendや外部APIを利用するツールを追加する場合は、必要なデータ送信について適切に明示する。

---

# 6. レスポンシブ対応

PCでの利用を主対象とする。

スマートフォンでも最低限以下を満たす。

* ツール一覧を閲覧できる
* 検索できる
* カテゴリを選択できる
* ツールを操作できる
* 不要な横スクロールが発生しない

---

# 7. 非機能要件

* 一般的なモダンブラウザで動作する
* 初期表示やツール操作が快適である
* 新しいツールを追加しやすい構造とする
* 不要な外部ライブラリを増やさない
* Backendが不要な機能ではBackendを使用しない
* ユーザー入力を不要に外部へ送信しない

---

# 8. Version 0.1 対象外

以下はVersion 0.1では実装しない。

* ユーザー登録
* ログイン
* データベース
* クラウド同期
* Spring Boot Backend
* AWS
* 課金
* 広告
* アフィリエイト
* Analytics

これらは必要性が発生した段階で検討する。
