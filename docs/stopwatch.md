# ストップウォッチ

既存32ツールに同等機能がないことを確認し、一般向けの1ツールとして追加。

- 注入した単調時計の起点差分で計測。表示更新が計測時間を加算しない。
- 100ms表示更新。非表示タブはタイマーを停止し、復帰時に差分を取得。
- 一時停止中は除外。負・逆行・非有限の時計値を防御し、連打でラップを逆転させない。
- 合計と区間の100ラップ。時間は24hで折り返さず、999:59:59.99で停止。
- OSスリープやブラウザ終了をまたぐ保証なし。離脱・pagehide・リセットで消去。
- 記録は端末メモリのみ。コピー時点のテキストを実Clipboard APIへ書く。非同期コピー通知は操作・離脱後に破棄。
- 時計表示はaria-live off。状態・ラップ・コピーの操作だけpolite通知。
- 既存明暗青UI、lazyルート、標準ボタンとfocus。新依存・権限・配信設定なし。

## 検証

- npm test: 134件成功。停止/再開/連打、表示更新なしの長時間、負・逆行・非有限時計値、区間/合計/100件、24h超/上限、コピー書式。
- lint/build/diff check成功。通常のtest:browserに専用回帰を統合。既存165ルート、74明暗モバイル確認、診断80レイアウト、画像/幅変換/文字数/縦横比/置換の回帰成功。時間計算・ランダム組み分け/ルーレットも専用回帰成功。
- ユーザーPCの既存Edgeを専用プロファイルで検証。Enter/Tab/Space、実Clipboard、停止中不変、100ラップ、上限到達時ラップ不追加、コピー失敗/競合、SPA離脱/再読込/リセット、10Hz以下の表示、320px明暗と画像目視を確認。実タブvisible→hidden→visibleと復帰時の経過継続も成功。OS時計/電源設定は変更しない。
- 途中で画面検証を親側の仮想PCへ移す指示を受け、通常Edgeは専用プロセスだけ終了。最後の上限境界調整と時間/ランダム回帰はheadlessで確認。headlessではnative背景タブを再現できないためTEST_NATIVE_BACKGROUND=0を指定し、その項目を明示的にSKIPする（通常Edgeでは調整前に成功）。新しい表示付きブラウザは起動しない。
- 本番UIの操作/目視は親側仮想ブラウザへ引き継ぐ。実機Safari、実スクリーンリーダー、OSスリープの精度は未検証。
