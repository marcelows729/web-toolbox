# 英数字の全角・半角変換

URL `/tools/width-converter`、ID `width-converter`、カテゴリ「テキスト・変換」。既存整形・置換には表記幅を揃える操作がないため追加し32ツール。

既定は英字・数字だけ。ASCII U+0021〜U+007Eと全角U+FF01〜U+FF5Eの対応から、英字／数字／ASCII記号を選ぶ。スペースだけはU+0020 ↔ U+3000。大小文字は維持。方向に合わない文字や対象OFFは保持する。NFKC・大文字化・カナ幅変換はしない。

全角チルダU+FF5EとASCII ~は対応するが、波ダッシュU+301Cは対象外。ASCII逆斜線と全角逆斜線は対応するが、円記号U+00A5/U+FFE5は対象外。ひらがな・カタカナ（半角含む）・漢字・濁点・丸数字・ローマ数字・単位記号・絵文字を一括正規化しない。ASCIIを含むキーキャップ絵文字は2〜3文字のシーケンスを検出して丸ごと保持する。

元の本文は上書きしない。入力・方向・対象の変更、リセット、離脱で共通useToolResultが結果と古いコピー通知を消す。文字列はHTMLとして解釈しない。入出力50,000 UTF-16単位。検査後に1対1のBMP対応だけを処理し、結果は入力と同じUTF-16長なので増幅しない。超過の貼付けは切り捨てずに拒否して元入力を保持。

既存テキスト整形の編集オフセット補助を再利用し、textareaでLFに見える場合も原入力のCRLF・CRを維持する。コピーAPIに渡す生文字列も保持する。クリップボード側の改行形式は環境で変わり得る。本文・設定・結果はメモリのみで、保存・送信・URL埋込みなし。棚はIDのみ。lazyルート・既存blue/navy UIを使用し、新依存・設定なし。

検証: npm testの`tests/width-converter.test.mjs`で全ASCII94文字、往復、既定/対象OFF、チルダ/円記号、互換文字、日本語/濁点/emoji/改行、空入力、変更数、上限・増幅なし・登録・棚を確認。通常npm run test:browser内の`tests/width-converter-browser.mjs`で明暗1280/320px、ネイティブEnter、実コピー、コピーAPIへ渡したCRLF、原本文保持、HTML、方向/対象変更、上限拒否、古いコピー通知、reduced-motion、非保存・非送信・URLを検証。
