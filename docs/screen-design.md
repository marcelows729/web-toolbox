# Screen Design

## 目的

Web Toolbox全体の画面構成と、各ツールで共通して使用するUI方針を定義する。

本プロジェクトでは、ツール数が増えても目的のツールを探しやすく、各ツールを同じ感覚で操作できることを重視する。

---

## 1. 共通レイアウト

全ページで以下の基本構成を使用する。

```text
+--------------------------------------------------+
| Header                                           |
| ぽけつる                                         |
+--------------------------------------------------+

| Main Content                                     |
|                                                  |
| ページ固有の内容                                 |
|                                                  |

+--------------------------------------------------+
| Footer                                           |
+--------------------------------------------------+
```

### Header

Headerには以下を表示する。

* サイト名 `ぽけつる`
* トップページへのリンク

初期バージョンではナビゲーションを増やしすぎない。

必要になった場合のみ、カテゴリ一覧やその他ページへのリンクを追加する。

### Footer

初期バージョンでは簡潔な表示とする。

将来的に以下の追加を検討する。

* About
* Privacy Policy
* GitHub
* お問い合わせ

---

# 2. トップページ

## 目的

利用可能なツールを一覧表示し、目的のツールへ素早くアクセスできるようにする。

## 画面イメージ

```text
ぽけつる

ちょっと便利なツールを、ポケットに。

+----------------------------------------------+
| ツールを検索...                              |
+----------------------------------------------+

[ すべて ] [ 開発 ] [ テキスト・変換 ]
[ 日時 ]   [ ネットワーク ] [ その他 ]


開発

+----------------------------------------------+
| JSON Formatter                               |
| JSONを整形・圧縮します                       |
+----------------------------------------------+

+----------------------------------------------+
| SQL IN Generator                             |
| 値の一覧からSQLのIN句を生成します           |
+----------------------------------------------+

+----------------------------------------------+
| Timestamp Converter                          |
| Unix Timestampと日時を相互変換します       |
+----------------------------------------------+


テキスト・変換

+----------------------------------------------+
| 文字数カウンター                             |
| 文字数・行数・単語数・バイト数を確認         |
+----------------------------------------------+

+----------------------------------------------+
| Text Diff                                    |
| 2つのテキストの差分を確認します             |
+----------------------------------------------+
```

---

## 2.1 ページタイトル

以下を表示する。

```text
ぽけつる
```

補足説明として以下のような文章を表示する。

```text
ちょっと便利なツールを、ポケットに。
```

文章は将来的に変更可能とする。

---

## 2.2 ツール検索

ツール一覧の上部に検索欄を配置する。

### 検索対象

以下を対象とする。

* ツール名
* description
* keywords

### 例

入力：

```text
json
```

検索結果：

```text
JSON Formatter
```

入力：

```text
差分
```

検索結果：

```text
Text Diff
```

検索処理は初期段階ではブラウザ上で行う。

---

## 2.3 カテゴリ

検索欄の下にカテゴリフィルターを配置する。

初期カテゴリ：

* すべて
* 開発
* テキスト・変換
* 日時
* ネットワーク
* その他

カテゴリはツール数に応じて追加・変更可能とする。

ツール数が少ないカテゴリを過度に細分化しない。

例えばSQL関連ツールが少ない間は「開発」に含める。

SQL関連ツールが増えた場合は、将来的に「SQL」カテゴリとして分離可能とする。

---

## 2.4 ツール一覧

各ツールはカード形式で表示する。

### Tool Card

表示項目：

* ツール名
* 短い説明
* カテゴリ

例：

```text
+----------------------------------------------+
| JSON Formatter                               |
| JSONを整形・圧縮します                       |
| 開発                                         |
+----------------------------------------------+
```

カード全体をクリック可能とし、個別ツールページへ遷移する。

---

# 3. ツール詳細ページ

## 目的

各ツールの操作と、そのツールに関する説明を1ページで提供する。

## 共通構成

```text
JSON Formatter

JSONを整形・圧縮できます。

--------------------------------------------

ツール操作領域

--------------------------------------------

このツールとは

--------------------------------------------

使い方

--------------------------------------------

関連ツール

--------------------------------------------

Privacy Information
```

ツールごとの機能は異なるが、ページ全体の構造は可能な限り統一する。

---

# 4. ツールヘッダー

ページ上部に以下を表示する。

* ツール名
* 短い説明

例：

```text
JSON Formatter

JSONを整形・圧縮できます。
```

必要になった場合はカテゴリも表示可能とする。

---

# 5. ツール操作領域

ツール固有の機能を配置する。

入力・操作・出力という基本的な流れを可能な限り統一する。

```text
Input

[ 入力エリア ]

[ 実行 ] [ その他操作 ]

Output

[ 出力エリア ]

[ Copy ]
```

ただし、すべてのツールに入力・出力エリアが存在するとは限らない。

ツールの用途に応じて適切なUIを使用する。

---

# 6. JSON Formatter

初期実装対象とする。

## 6.1 画面構成

```text
JSON Formatter

JSONを整形・圧縮できます。

Input

+----------------------------------------------+
| {"name":"test","items":[1,2,3]}             |
|                                              |
|                                              |
+----------------------------------------------+

[ Format ] [ Minify ] [ Clear ]

Output

+----------------------------------------------+
| {                                            |
|   "name": "test",                            |
|   "items": [                                 |
|     1,                                       |
|     2,                                       |
|     3                                        |
|   ]                                          |
| }                                            |
+----------------------------------------------+

[ Copy ]
```

---

## 6.2 Input

複数行入力可能なテキストエリアを使用する。

ユーザーがJSON文字列を入力する。

---

## 6.3 Format

入力されたJSONを解析し、読みやすい形式に整形する。

例：

入力：

```json
{"name":"test","items":[1,2,3]}
```

出力：

```json
{
  "name": "test",
  "items": [
    1,
    2,
    3
  ]
}
```

---

## 6.4 Minify

入力されたJSONを解析し、空白・改行を除去した形式に変換する。

例：

```json
{"name":"test","items":[1,2,3]}
```

---

## 6.5 Clear

入力と出力を初期状態に戻す。

エラー表示も削除する。

---

## 6.6 Copy

出力結果をクリップボードへコピーする。

コピー成功時は、ユーザーが成功したことを認識できる簡単なフィードバックを表示する。

例：

```text
Copied
```

または

```text
コピーしました
```

---

## 6.7 Error

入力されたJSONが不正な場合はエラーを表示する。

例：

```text
JSONの解析に失敗しました。
```

可能であれば、JavaScriptが返す具体的な解析エラーも補助情報として表示する。

エラー発生時にアプリケーション全体が停止しないようにする。

---

# 7. ツール説明

ツール操作領域の下に、そのツールの概要を表示する。

例：

```text
## JSON Formatterとは

JSON Formatterは、JSON文字列を読みやすい形式に整形したり、
不要な空白や改行を削除して圧縮したりするためのツールです。
```

説明文は過度に長くせず、そのツールを初めて使うユーザーでも用途を理解できる内容とする。

---

# 8. 使い方

各ツールページに簡単な利用手順を表示する。

JSON Formatter例：

```text
## 使い方

1. Input欄にJSONを入力します。
2. Formatを押すとJSONを整形します。
3. Minifyを押すとJSONを圧縮します。
4. Copyで結果をクリップボードへコピーできます。
```

操作方法が明らかな単純ツールでは、説明を簡略化してもよい。

---

# 9. 関連ツール

各ツールページ下部に関連ツールを表示する。

例：

```text
## 関連ツール

Base64 Converter
URL Encoder
Text Diff
```

関連ツールはTool Registryに登録された情報から取得することを想定する。

関連ツールをクリックすると、そのツールページへ遷移する。

関連ツールが存在しない場合は、このセクションを表示しなくてもよい。

---

# 10. Privacy Information

ブラウザ内で完結するツールでは、ユーザーが安心して利用できるよう以下の内容を表示する。

例：

```text
このツールの処理はすべてブラウザ上で実行されます。
入力したデータはサーバーへ送信されません。
```

外部APIやBackendを使用するツールについては、この表現を使用しない。

その場合は、必要に応じてデータ送信について明示する。

---

# 11. レスポンシブ対応

PCでの利用を主対象とする。

スマートフォンでも最低限以下を満たす。

* 横スクロールしない
* ボタンを操作できる
* 入力・出力領域を利用できる
* ツール一覧を閲覧できる

PCでは複数カラム表示、スマートフォンでは1カラム表示としてよい。

---

# 12. UI方針

## シンプルさ

装飾を増やしすぎず、ツールそのものを使いやすくすることを優先する。

## 一貫性

各ツールで以下の見た目・操作感を可能な限り統一する。

* ページタイトル
* 説明
* 入力欄
* ボタン
* 出力欄
* Copy
* Error
* 関連ツール

## 拡張性

新規ツール追加時に大規模な画面修正が不要な構造とする。

Tool Registryの情報から以下を生成できる設計を想定する。

* トップページの一覧
* 検索
* カテゴリフィルター
* 関連ツール

---

# 13. 初期リリース対象

初期実装では以下のみを対象とする。

### 共通

* Header
* トップページ
* ツール一覧
* 検索
* カテゴリフィルター
* ツール詳細ページの共通レイアウト
* レスポンシブ対応

### Tool

* JSON Formatter

その他のツールは初期共通基盤の動作確認後に追加する。
