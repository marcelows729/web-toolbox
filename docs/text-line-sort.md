# テキスト整形: 行の並べ替え

既存の40ツールに行の並べ替えはないため、`/tools/text-formatter`へ昇順・降順の選択を1件追加する。ツール数・URLは増やさず、既存の5つの独立した操作を維持する。

- 初期は「並べ替えない」。明示的な整形実行でだけ並べ替え、入力は上書きしない。
- 順序はブラウザの`Intl.Collator('ja-JP', { numeric: true, sensitivity: 'variant' })`による文字比較。数字部分は項目1→項目2→項目10。同じ照合順の行は昇順・降順とも元の順序を保持する。文字列をUnicode正規化・大小文字変換して書き換えない。
- 漢字の読み方による五十音順、負数・小数・日付の数値計算順、CSV列単位の並べ替えは対象外。ブラウザの照合情報により順序が異なる場合がある。
- 処理順は前後空白→空行削除→空行集約→完全一致の重複行除去→並べ替え→改行を空白に。並べ替えだけなら各位置の区切り（CRLF/LF/CR）と末尾の改行を保持する。途中の空行は並べ替え対象。末尾の空の最終行はその位置に保持する。先行する空行削除/重複除去が末尾の空行を消す場合は従来の挙動を維持する。
- 上限は既存の50,000 UTF-16単位・5,000行。超過は切り捨てず拒否し元入力を保持する。
- 順序・入力・既存操作の変更/リセット/再実行/離脱で既存useToolResultを通して古い結果・コピー通知を無効化する。リセットは既存5操作OFF・並べ替えNONE・空入力へ戻す。
- ブラウザ内処理のみ。保存・送信・URL埋め込み・新依存・外部API・設定変更なし。お気に入り/最近使用は既存ツールIDのみ。

7件の追加unitテストで数字順、日本語、同順保持、混在改行・末尾・空行、処理順、上限、初期UIと検索を検証する。既存の32操作組合せテストも継続する。専用headlessではlight/dark・320/375/768/1280・キーボード・コピー・古い通知抑止・リセット・HTMLを文字として扱うこと・入力保存/送信なしを確認する。実機Safariと実スクリーンリーダー、公開UIは未検証。

世界時計の未コミット18ファイルを前提とする後続差分。今バッチではcommit/push/配信を行わない。
