# 連番作成（2026-10-02）

既存35ツールは既存テキストの整形・変換等で、番号の連続生成がないため追加。36ツール目、ID sequence-generator、URL /tools/sequence-generator、一般カテゴリ。旧ID/URL・機能と棚保存形式は維持。既存のlazyルート、フォーム、useToolResult、検索、棚を利用し、依存/API/設定/入力保存は追加しない。

開始・件数・増分は必須。増分0を許可して同じ番号を繰り返す。桁数は任意、空欄/0でなし。負数は符号の外でゼロ埋めし、既に桁数が大きい番号を切り捨てない。前後文字をそのまま各行へ付け、LFで結び、末尾に改行を追加しない。Windowsの実クリップボード読取はOSによりCRLFとなるためブラウザテストで改行だけ正規化して比較する。

整数はBigIntで正確に扱う。全角数字・全角符号/マイナス記号と前後空白を数値欄だけで解釈。小数/指数/16進/カンマ/内部空白を拒否。開始・増分・生成番号は正負18桁以内、件数1〜10000、桁数0〜20、数値入力32文字、前後文字各100 UTF16単位・改行なし、結果100000単位に制限。単調な数列の最終番号と正確な出力長を、行の生成前に検査する。

長過ぎる入力や貼付けを切り捨てず拒否し、直前の入力を保持。結果は消してエラーを表示する。入力変更/初期化/再生成で古い結果とコピー通知を無効化。コピーはクリック時の結果を渡すが、待機中の変更後に古い通知を反映しない。コピー失敗時も結果を保持して手動コピーを案内する。入力と結果はメモリのみ。
